# M121 前置 · 模拟 persona 走查记录（非真人试点）

**本文档记录的是模拟走查，不是 M121 要求的真实用户观察。** 三名"参与者"是无产品上下文的
AI persona，读到的是真实界面文字；它们的首见误读是真实的文字歧义证据，但不能替代真人的
操作行为、用时与情绪数据。**M121 保持 `in_progress`，其完成条件（2–3 名真实目标用户）不变。**

## 方法

- 3 个相互独立、无本产品任何上下文的 persona（首见即测试材料）：
  - S1：大二学生，课程设计"社区图书馆"，无研究方法训练；
  - S2：大四竞赛队主力，"旧粮仓改美术馆"，两周交图，效率导向；
  - S3：工作 2 年建筑师，"旧办公楼改社区中心"，汇报证据焦虑。
- 材料：主页、建筑结果页（耕织图 Run）、图纸灵感结果页（轴测图 Run）、收藏目录与详情的
  **真实页面文字**（当日 DOM 抓取），任务与判据取自 `docs/m121-pilot-kit.md` 的 T1/T2/T9/T3/T5/T6/T7/T8 与结束访谈。
- 分级沿用工具包第 6 节：跨 persona 重复 ≥2 才立项；已立项修复走红绿与完整门禁。

## 记录但未修（属已定设计决策或需另行立项，待真人试点或用户裁决）

1. **结果页与收藏页无出处链接（S3 的最大不信任源）**：S3 明确表示"没有链接，每个案例都要
   自己重新核一遍……越靠近产出的页面越需要出处"。这与 M128 用户亲自批准的"答案优先、去来源化"
   方向相反，是**专业用户信任与阅读纯净度的直接冲突**，需要用户裁决（例如仅在收藏详情恢复一个
   "打开原文"链接）。
2. **"做跨案例论证"论文腔**（S1 不敢选、S2 认为与己无关）：属 M75 定稿的三档收获词汇，未擅改。
3. **三档无时长预估**（S2：超过半小时就回小红书）：M135 核验意见是未实测前不写时长；需要先
   实测各档真实耗时再补。
4. **检索相关性**（S3：儿童房混进耕织图研究"明显不合理"）：属研究质量而非文案；该 Run 正是
   pre-M124 的"初步依据"记录，新状态标签已更清楚地传达这一点。
5. "选择案例"与收藏关系、"结果板/来源板"产物形态、"本地研究工具"含义：单人困惑，记录待真人复验。

## 与真人试点的关系

模拟只能测**文字可理解性**；任务完成率、用时、导航路径、真实情绪与恢复预期仍必须由真人得出。
上表"未修"项应作为真人试点的重点观察点带入 `docs/m121-pilot-kit.md` 的对应任务。
