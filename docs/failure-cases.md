# 失败案例与恢复策略

ArchResearch 的基本原则是：后续阶段失败时不丢弃已经取得的可用资产；没有充分证据时降低结果等级，而不是补写事实。

## 状态语义

| 终态 | 含义 | 用户下一步 |
|---|---|---|
| `completed` | 覆盖与结果强度门槛同时达标 | 阅读案例答案、对照、收藏和导出 |
| `partial` | 已有可用资产，但覆盖不足或后续工具失败 | 先使用已有结果，再重试缺口 |
| `blocked` | 研究正常结束但没有可用资产 | 调整问题、输入或浏览器权限后重试 |
| `cancelled` | 用户主动取消；已有检查点保留 | 稍后重试同一次运行 |
| `failed` | 未取得资产前发生未恢复错误 | 查看研究阶段和诊断信息，稍后重试 |

## 失败恢复矩阵

| 场景 | 系统如何发现 | 结果与保留内容 | 恢复方式 | 对应离线覆盖 |
|---|---|---|---|---|
| 模型服务超时、限流或结构化输出失败 | 本地 Provider client 抛错；正文分析单次 45 秒且不对同一页面立即二次请求 | 有证据时 `partial`，否则 `failed`；检查点、查询和已有证据保留。项目正文不完整时改用一次、最多两页的定向文字补查 | 使用已有结果；稍后重试或缩小问题范围 | Provider Mock、项目补查与 Python workflow 测试 |
| 总时间预算耗尽 | 每次供应商调用之间比较运行截止时间 | 有资产时 `partial`，`stop_reason=time_budget_exhausted` | 使用已有结果，或新建更聚焦问题 | 预算与工作流单测 |
| 图纸逐图检查容量耗尽 | 视觉任务达到 48 个逐图槽位或 48 MiB 预览上限 | 保留已有帖子和图片；未达到三帖目标时 `partial`，`stop_reason=visual_budget_exhausted` | 先使用现有方向和帖子；不要把该原因误判为运行超时 | 三方向最坏四帖、恢复终态与 Board 文案测试 |
| 连续两批无新增资产 | 每批持久化后的新增数量为 0 | 有资产时 `partial`，`stop_reason=no_new_assets`；无资产为 `blocked` | 收窄问题、补充中英文术语或限定可信域名 | 30 条任务的 `expected_coverage.expected_gaps` |
| Chrome 扩展未连接或中途断线 | 本地 loopback bridge 超时或 WebSocket 关闭 | 小红书图纸方向保留，未取得的页面标为跳过；扩展打开的受管标签关闭，已授予权限保留 | 保持 Windows 应用运行，回到本地页面点击“连接 Chrome 读取高清图纸”；已保存 pairing 可自动恢复 | 持久 Chromium 断线用例、浏览器协议单测 |
| 动态页面持续加载、永不进入 `document_idle` | 后加载脚本会卡在首条页面命令 | 受管 tab 在 `loading` 阶段预装固定监听器；就绪失败在 5 秒内关闭标签并返回可恢复错误 | 无需重复连接或授权；已有结果保留 | 永不结束 HTTP 响应的 packaged-Chrome E2E、注入时序与重试单测 |
| 已有研究运行时再次新建或重试 | FastAPI 单活研究租约发现活动 Run | API 返回 409，不创建第二个 Run、不抢占现有标签 | 等待当前研究完成，或先取消再等待状态结束 | API 单活租约与终态回归 |
| 登录态 Chrome 检视失败 | 本地 API 的浏览器命令超时、权限拒绝或标签断线 | 保留已取得的页面与图片线索；未分类图片不升级事实、归属、版权或结果等级 | 重连扩展后重试图纸灵感；已有建筑证据不丢失 | 浏览器客户端、正常增强、歧义线索和 Trace 测试 |
| 公开网页读取、搜索或解析失败 | Python Direct Playwright 超时、被拒绝或解析器抛错 | 当前页面标为跳过，其他来源与已有结果全部保留；正文不进入 Trace | 稍后重试或换一个公开来源；不恢复 Firecrawl 降级 | 页面读取、错误隔离、URL 与重定向安全测试 |
| 用户拒绝或主动撤销站点权限 | 扩展报告 `permission_required` | 不读取网页；已有搜索资产不丢失 | 必须在扩展 UI 中由直接用户手势授权可选 `<all_urls>`；授权后持续有效，导航仍只允许公网 HTTP/HTTPS | 权限服务、控制器与持久权限 E2E |
| 页面需要登录、验证码或反自动化挑战 | 页面内容不可访问、媒体为空或动作超时 | 暂停该页并保留已有结果；允许显式人工接管，不自动解验证码或绕过访问控制 | 用户在浏览器中完成允许的登录/验证后继续；也可跳过该页 | replay 动态页和错误路径 |
| 恶意页面提示注入 | 页面含“忽略指令”、隐藏表单或敏感区域 | 内容仅作不可信数据；不改变动作、预算或系统指令 | 无需用户处理；继续研究或拒绝该来源 | `fixtures/pages/malicious-page.html` |
| 私网/内网重定向 | API 与扩展 URL 检查发现非公网地址 | 拒绝导航，不下载内容，Trace 只记脱敏错误类型 | 使用公开 HTTP(S) 来源 | 恶意页面的链路本地 URL、URL 安全测试 |
| 无限滚动、超大图或媒体过多 | 滚动距离、截图面积、候选数、页面数受协议和预算限制 | 超界动作拒绝；已枚举候选保留 | 使用页面内可见候选或其他来源 | 协议边界与截图测试 |
| 图片无法确认项目归属 | 来源文字和页面关系不足 | `asset_association=unknown/probable`，结果降为 `partial` 或 `visual_lead` | 通过出处链接回源网页人工核对；不得把视觉相似当成事实 | Evidence schema 与排序测试 |
| PDF 文本为空或 OCR 不可靠 | 提取不到足够文本或页图分类置信不足 | 保留 PDF 页码和可见区域，不生成无定位事实 | 换清晰 PDF/图片，或人工补充项目文字 | PDF 输入和 EvidenceClaim 校验 |
| Windows 应用升级、卸载或更换电脑 | 安装目录变化，但用户数据目录独立 | 覆盖升级和卸载保留 `%LOCALAPPDATA%\ArchResearch\data`；更换电脑不会自动同步 | 升级前下载 ZIP 备份；在新电脑安装后显式恢复 | 安装器覆盖升级、卸载数据保留与备份恢复测试 |
| 用户取消 | 本地 API 写入 `cancelled` | 当前结果和 Trace 保留，研究标签页关闭，已授予权限保留 | 点“重试”继续同一运行；需要时从扩展主动撤销 | cancel/retry 集成测试 |
| 分享导出包含未知或受限图片 | 确定性权利门禁检查 `rights_status` | 分享版只写来源卡、署名和链接；私有版不受此门禁 | 获得许可并更新权利状态，或使用私有研究版 | board export 单测 |
| 临时裁图过期 | 启动清理发现候选文件超过 7 天 | 来源元数据可能仍在 30 天窗口内；已收藏快照长期保留 | 重新研究该来源；收藏重要结果 | lifecycle TTL 测试 |

## 不应恢复成“成功”的情况

- 找到视觉相似图片，但项目名称或图片归属冲突；
- 聚合站转载图存在，但没有可信项目页或出版物支持；
- 页面声称图片是开放许可，但没有可定位的许可文本；
- 模型根据构图猜测设计意图、结构性能或运营效果；
- ArchDaily 等公开建筑网站阻止访问或要求验证码。

这些情况应保留为 `visual_lead`、`partial` 或 `blocked`，并在卡片中写清适用边界。公开页允许隔离浏览器、稳定 UA/指纹兼容、合理节流与重试；登录页允许用户显式接管当前受管标签。系统不自动解验证码，不绕过付费墙或访问控制，不默认轮换代理，也不读取 Cookie、密码或私信。

## 故障排查顺序

1. 查看参考板右侧研究阶段和诊断信息，记录 `stop_reason` 与最后完成阶段。
2. 检查 Windows 应用是否仍在运行、扩展“本地服务”是否已连接、网页读取权限是否由用户明确授予。
3. 刷新本地页面后重试；若仍失败，换一个公开来源、缩小问题范围或重新验证 Provider 配置。
4. 只对 `partial`、`blocked`、`cancelled` 或 `failed` 使用重试；`completed` 不会重复执行。
