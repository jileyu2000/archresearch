# ArchResearch 本地演示流程

普通用户先安装 Windows 应用；只有图纸灵感需要另外加载 Chrome 扩展。下面第一条使用固定本地数据，不需要 Key；第二条使用用户自己的 Provider 和实时网页。

## 演示前检查

Windows 安装版：

1. 从桌面或开始菜单打开 ArchResearch。
2. 首次启动填写 API 接口地址和 API Key，从上游模型列表选择模型；只看固定回放时可以关闭配置窗口，直接使用 demo URL。
3. 图纸灵感按[Chrome 扩展安装说明](chrome-extension.md)加载独立扩展 ZIP。
4. 在 ArchResearch 本地页面点击“连接 Chrome 读取高清图纸”，首次提示时允许网页读取。

源码维护者使用：

```powershell
pwsh -NoProfile -File scripts/validate-evaluation-fixtures.ps1
pwsh -NoProfile -File scripts/start.ps1
```

完成后运行：

```powershell
pwsh -NoProfile -File scripts/stop.ps1
```

## 流程一：固定 mock 回放

**目标**：演示完整工作界面、证据分区、收藏和导出，不调用外部 Provider 或公开网页。

安装版使用启动器当前端口，源码环境默认使用 5173：

- 快速找方向：`http://127.0.0.1:<当前端口>/?demo=quick`
- 形成方案依据：`http://127.0.0.1:<当前端口>/?demo=balanced`
- 做跨案例论证：`http://127.0.0.1:<当前端口>/?demo=deep`

1. 打开任一 demo URL。三个入口不会创建 Workspace 或 ResearchRun。
2. 核对结果按“任务 -> 研究结论 -> 问题章节 -> 完整案例答案”连续展开。
3. 每个案例只显示项目名、机制、最多三条做法、一条适用条件、至多一张识别图和一个“出处 · 域名”链接。
4. 在案例选择条中勾选两个案例加入个人收藏；再次保存同题新案例时，旧收藏不能被替换。
5. 选 2-6 个案例打开“对照案例策略”，核对解决对象、可借鉴方法、图中看到和适用条件。
6. 生成可分享结果板；未知或受限图片应降级为来源卡、署名和链接。

**完成判据**：无需 Key 即可看到非空案例答案；收藏保存是累加动作；分享版不嵌入未知或受限图片。

## 流程二：本地实时研究

**目标**：演示本地 Python workflow 的多轮网页搜索、证据绑定、缺口恢复和图纸灵感。

**费用与隐私提示**：模型调用使用用户自己配置的 Provider。API Key 在 Windows 凭据管理器中，Workspace、Run、文件和结果保存在本机。

1. 打开正常的 ArchResearch 本地页面，新建项目“中小型博物馆流线”。
2. 选择“建筑设计研究”，输入“中小型博物馆中如何分离观众、工作人员和藏品运输三套流线？”，研究方式选“做跨案例论证”。
3. 研究在本机后台运行。回到主页后，从“最近研究”重新打开该 Run。
4. 结果出现后按问题章节阅读案例答案，并通过“出处 · 域名”回到源网页核对。
5. 用“对照案例策略”比较至少两个项目的流线做法和适用条件。
6. 若结果为 `partial`，确认已有证据仍保留，再使用重试；只有 coverage 与 enrichment 同时达标才进入 `completed`。
7. 切换到“图纸灵感”，输入“低饱和分层轴测图如何区分保留结构与新增体量？”。
8. 确认本地页面显示 Chrome 扩展已连接；运行后检查结果按“灵感方向 -> 帖子 -> 帖子内图片”组织，并能打开原笔记。
9. 结束后确认扩展打开的受管标签已关闭；需要收回权限时，在扩展中点击“撤销网页读取权限”。

**完成判据**：结果来自当次本地实时研究；正式事实能跳转到逐字证据来源；失败页面不会清空已有资产；图纸灵感只来自小红书。

## 版本化真实评测记录

25 条任务的数据集本身不会联网。真实评测由操作者逐条主动启动，并记录：

- `evaluation_date` 与任务 `id`
- 应用版本或 Git commit
- Provider、研究模型和视觉模型，不记录 Key
- 查询数、访问页面数、运行时间与费用
- 最终状态、`stop_reason` 和 CoverageReport
- Top-5 图纸类型人工标注、重复项和来源归属
- 网页变化、验证码或访问规则造成的差异

不要在 CI 或默认 `scripts/verify.ps1` 中批量执行真实任务。
