# Product

## Register

product

## Users

使用 ArchResearch 的建筑学生和青年设计师。他们在 Chrome 中已经打开研究工作台或登录态网页，希望继续研究，而不是配置浏览器基础设施。

## Product Purpose

在用户明确授权后，把 Web Edition 与 Chrome 的可见网页连接起来，执行受限的页面读取、图纸枚举和裁图动作。扩展使用用户已登录的小红书会话执行只读搜索，只返回经过裁剪的公开笔记 URL、缩略图 URL 与可见文字，不返回 Cookie、账号、浏览器存储或登录凭据。成功意味着用户只需安装一次、连接一次当前公共网页并完成一次网页读取授权；权限保留到用户主动撤销或卸载扩展，普通用户不需要输入端点、配对码或启动本地服务。

## Brand Personality

直接、清醒、可靠。状态说明像一位熟悉浏览器安全边界的助手：先告诉用户已经完成什么，再明确还差哪一步，不使用基础设施术语制造压力。

## Anti-references

- 不向普通用户展示一次性配对码、本地 WebSocket 地址或手动连接表单。
- 不用笼统的“连接失败”覆盖权限拒绝、服务断开和配对失效等不同问题。
- 不静默申请全站读取权限；授权必须来自扩展界面的直接用户手势，并始终提供明确撤销入口。不读取 Cookie、浏览器存储、密码、私信或账号身份。
- 不执行评论、发布、点赞、关注、购买或普通表单提交。

## Design Principles

- **当前网页优先：** 用户从扩展工具栏连接当前 Web Edition 网页；连接状态和权限状态始终用可读文字呈现。
- **一步一个动作：** 当前唯一待办成为唯一主按钮，按钮直接描述结果。
- **状态与修复对应：** 每个错误说明发生了什么，并提供唯一、具体的下一步。
- **一次授权、随时撤销：** 授权文案明确权限会保留；用户可在扩展中主动撤销，研究终态仍关闭 Agent 打开的标签页。
- **研究读取器只进受管标签：** 持续加载页面从受管 tab 的 loading 阶段安装固定读取器，API 收到 tab id 时最新导航的监听器已经就绪；重定向、终态与断线都使旧代次失效，私网跳转立即关闭。受管 tab id 只保存在 Chrome 会话存储，用于工作线程重启后的清理。
- **公共桥接由用户点选：** 用户在扩展弹窗选择“连接当前 ArchResearch 网页”后，扩展才为这个精确 HTTPS origin 注册轻量消息桥；桥只在带公共版标记的页面启动，只接受状态和小红书搜索两种命令。它不是网页研究读取器，不能接收 URL、脚本、选择器、表单或社交动作。
- **安全边界可理解：** 用用户语言说明不会读取的内容，不要求用户理解协议或令牌。

## Accessibility & Inclusion

以 WCAG 2.2 AA 为目标。所有状态同时使用文字而非只依赖颜色；支持键盘操作、可见焦点和至少 44px 的主要触摸目标；错误与成功反馈通过可访问的实时区域播报。
